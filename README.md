# dota2-video-studio

**Human idea → Grok storyboard + Dota 2 style frames → local PC render → finished mp4**

Adapted from [tvhead-studio](https://github.com/Vladic20/tvhead-studio).
Grok does the creative work (scene breakdown + image generation in official Dota 2 painterly style). Your machine does the final assembly with ffmpeg (Ken Burns, timing, optional TTS, captions).

## What you get

- Horizontal 1920×1080 (or preview 1280×720) narrated video
- English / Russian (or both)
- Frames generated by Grok in Dota 2 art style (Valve loading-screen aesthetic)
- Local render — no cloud video service needed

## Quick start

```bash
cd dota2-video-studio
cp .env.example .env          # optional: add OpenRouter key for free TTS
node render.mjs example       # renders the included example
```

Output: `out/example.en.mp4` (+ `.srt`)

## Workflow (for Grok / agent)

1. Human gives an idea / topic.
2. Grok writes `episodes/<slug>/story.json` with scenes, narration (`say` EN/RU), and detailed `prompt` for each frame.
3. Grok generates the images (Dota 2 style) and saves them as `episodes/<slug>/frames/scene_01.jpg`, etc.
4. Run: `node render.mjs <slug>`

See `SKILL.md` for the exact instructions the agent should follow.

## Requirements

- Node ≥ 18
- ffmpeg in PATH
- (optional) OpenRouter API key for Fish Audio free-tier narration

## Example

The `episodes/example/` folder already contains three Dota 2 style frames generated by Grok and a bilingual story. Just run the renderer.
