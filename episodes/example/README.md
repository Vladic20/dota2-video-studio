# Example episode — already has frames

This folder contains a ready-to-render example:

- `story.json` — bilingual (EN/RU) 3-scene story
- `frames/scene_01.jpg` … `scene_03.jpg` — Dota 2 style images generated by Grok

Run from the project root:

```bash
node render.mjs example
```

You will get `out/example.en.mp4`.
